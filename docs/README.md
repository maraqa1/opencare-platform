# Documentation Scaffold

This directory holds operational and architecture documentation for the OpenCare Insight Platform.

- `repo-roadmap.md`: current repo delivery roadmap and implemented phase summary
- `acceptance-matrix.md`: exact validation commands and expected results for Phase 1
- `phase1-diagnosis.md`: retrospective diagnosis of the Phase 1 workflow and root causes
- `phase2-diagnosis.md`: retrospective diagnosis of the Phase 2 analytics loop and proof boundaries
- `phase2-analytics-loop.md`: Phase 2 analytics loop and repeat-cycle validation
- `phase4-investor-dashboard.md`: investor-facing portal, analytics, and extensibility work for Phase 4
- `phase4b-governance-trust-layer.md`: lineage, dictionary, freshness, quality, and compliance trust layer
- `use_cases/use_case_contract_lessons.md`: lessons learned from Revenue Cycle Management to tighten future use-case contracts
- `use_cases/golden_use_case_package_template.md`: canonical golden bundle structure for future use-case shells
- `use_cases/templates/use_case_contract_template.md`: reusable use-case contract with locale, dashboard, runtime, and capability truth requirements
- `use_cases/templates/dashboard_contract_template.md`: reusable dashboard contract with business, binding, and governance fidelity rules
- `use_cases/templates/dashboard_implementation_matrix_template.md`: required contract for non-substitutable dashboards
- `use_cases/templates/story_flow_template.md`: required narrative order and dashboard journey contract
- `use_cases/templates/dashboard_fidelity_contract_template.md`: acceptance contract proving dashboards were implemented without substitution
