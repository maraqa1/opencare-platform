- title
- Arabic subtitle where required
- current value

- threshold rail
- status badge

For an active case banner:

- alert label

- problem statement
- risk score
- forecast or breach signal
- owner or team
- primary CTA

For a runtime card:

- runtime name
- status
- image or model reference
- last run
- duration
- evidence output

## Rules

- Anatomy is part of the contract, not styling trivia.
- A component with missing required anatomy is not faithful even if the data is present.
