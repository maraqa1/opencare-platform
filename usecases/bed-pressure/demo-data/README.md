# Demo Data

The current demo data is generated by the platform seed and runtime processes, not by static CSVs in this bundle.

Expected demo tables:

- `analytics.fct_bed_occupancy`
- `output.forecast`
- `output.anomaly`
- `decision.decision_queue`

When `decision.decision_queue` is empty, the portal renders labelled preview candidates for demonstration only. Those candidates do not write audit events.
