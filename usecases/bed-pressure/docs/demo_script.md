# Bed Pressure Demo Script

1. Start on Current Status and show wards sorted by pressure.
2. Open Predictions and explain which wards are forecast to cross the 90 percent threshold.
3. Open Analysis and show KPI values, trend, pressure mix, top wards, and executive actions.
4. Open Decisions and explain the chain: signal, decision, action, outcome.
5. If the live queue is empty, show the labelled demo candidates and then use Generate Live Queue to persist real decisions.
6. Close with governance: every operational action is linked to source data, runtime evidence, audit log, and outcome measurement.
