# Demo Data

RCM demo data is generated by `scripts/demo/generate_demo_data.py`.

The generated raw SQL contains:

- `rcm_claims`
- `rcm_financial_postings`
- `rcm_referrals`

The complete handover zip includes:

- `raw-data/opencare_demo_mysql.sql`
- `raw-data/opencare_demo_validation.sql`
- `raw-data/opencare_demo_summary.json`

These files also include shared Bed Pressure demo tables because the current demo generator seeds both use cases.
