# Revenue Cycle Management Handover Package

## Purpose

This handover package gives an implementation team enough context to rebuild, validate, demo, and operate the Revenue Cycle Management use case on OpenCare or on another platform with similar components.

## Current Status

- Branch: `dev`
- Use case package: `usecases/revenue-cycle-management`
- Package standard: `golden-bundle-1.8.12-candidate`
- Use case status: demo-ready and production-portable with finance source mapping.

## Included

- Golden bundle contracts.
- Source data and metadata documentation.
- dbt model documentation.
- Backend API and runtime documentation.
- Portal implementation documentation.
- Decision workflow and governance documentation.
- Complete handover zip with raw demo data.
